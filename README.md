# Portfólio Gabriel Gobira

Site estático em HTML, CSS e JavaScript.

## Publicar no GitHub Pages
1. Crie repositório público `portfolio`.
2. Envie `index.html`, `estilo.css` e `script.js` na raiz.
3. Em Settings > Pages, selecione Deploy from a branch, `main` e `/ (root)`.
4. Acesse `https://GabrielGobira.github.io/portfolio/`.
